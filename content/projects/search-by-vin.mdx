# Search by VIN

A Next.js app that decodes a Vehicle Identification Number and displays the resulting vehicle details, backed by the NHTSA's public decoding API.

## Technical Highlights

- **VIN Decoding**: Queries the NHTSA (National Highway Traffic Safety Administration) API to resolve make, model, and other details from a VIN.
- **Auth**: User authentication handled through Supabase.
- **UI**: Responsive interface built with shadcn/ui components and real-time toast feedback.
