# Graphiti MCP Server

A fork of Graphiti packaged and self-hosted on Coolify, exposing its temporal knowledge-graph engine to AI agents through the Model Context Protocol.

## Technical Highlights

- **MCP Integration**: Wraps Graphiti's graph engine as MCP tools any compatible agent can call directly.
- **Self-Hosted**: Runs on Coolify as part of the homelab stack instead of a hosted third-party service.
- **Temporal Memory**: Builds real-time, temporally-aware knowledge graphs agents can query for long-term context.
