# Refinery

A local-first command center for supervising coding agents. It is in early development, and live tool execution is not enabled yet.

## What it does

- Shows agents and their runs on a 3D office floor built with React Three Fiber.
- Stores provider keys encrypted, so they stay on your machine.
- Runs text prompts against local Ollama or OpenRouter models and keeps run history in SQLite.
- Includes a sandboxed runner for coding agents, which stays switched off until tool execution is ready.
