# Transcribe-Script

A Python pipeline that turns audio recordings into structured notes in an Obsidian vault. Transcription and formatting both run on your own machine.

## What it does

- Transcribes audio locally with Whisper.
- Formats each transcript into a note with Ollama, including Obsidian metadata.
- Sends finished notes to Obsidian through its Local REST API.
- Offers a Streamlit app for file upload, microphone and desktop audio capture.
