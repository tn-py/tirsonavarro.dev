# Notes and Tasks App

A single-page personal dashboard for tracking tasks and jotting notes side by side, live at [notes-and-tasks.vercel.app](https://notes-and-tasks.vercel.app).

## Technical Highlights

- **Tabbed Workflow**: Switches between a task list with completion toggles and timestamped freeform notes.
- **Persistent State**: Tasks, notes, and theme preference are saved to `localStorage`, so state survives a refresh.
- **Dark Mode**: Full light/dark theme toggle built with Tailwind CSS.
