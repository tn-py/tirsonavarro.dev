# Expo Shopify Storefront

An open-source Expo template that turns a Shopify store into a native iOS and Android app. Demo mode runs against mock.shop, so you can try it before connecting a real store.

## What it does

- Browses collections and products, searches, and manages the cart through Shopify's Storefront API.
- Signs customers in with Customer Account auth and carries that login into checkout.
- Runs checkout inside the app with Shopify's Checkout Sheet Kit.
- Includes unit tests and end-to-end tests for the main app flows.
