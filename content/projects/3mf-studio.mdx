# 3MF Studio

A viewer and editor for 3MF files, the project format used for 3D printing. It runs entirely in the browser. It is in progress and not deployed yet.

## What it does

- Opens a 3MF file and unpacks it client-side, with no server upload.
- Shows the model in 3D with three.js and camera controls.
- Lets you select parts of the model and change their colors and materials.
- Covers the parser, materials and selection logic with automated tests.
