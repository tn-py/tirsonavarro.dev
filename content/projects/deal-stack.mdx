# Deal Stack

A real-time multiplayer card game for 2-5 friends. Players share one table, and the game rules are enforced on the server instead of in the browser.

## What it does

- Keeps every player's screen in sync with Supabase Realtime.
- Enforces the rules server-side in Postgres, through SQL migrations.
- Uses React and Vite for the game interface.
- Covers the game logic with automated tests.
