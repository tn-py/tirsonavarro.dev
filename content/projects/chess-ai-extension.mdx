# Chess AI Extension

A Chrome extension that runs a full chess game against a computer opponent directly in the browser popup — no tab switching required.

## Technical Highlights

- **Full Rule Set**: Implements standard chess rules end-to-end, including check detection and legal-move validation.
- **Adjustable Difficulty**: Easy, Medium, and Hard settings change how the AI selects among legal moves.
- **Self-Contained**: Runs entirely client-side in the extension popup, no backend required.
