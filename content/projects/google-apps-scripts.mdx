# Google Apps Scripts

A working collection of Apps Script tools built to automate recurring Shopify and spreadsheet tasks without paid third-party apps.

## Technical Highlights

- **Shopify Tools**: Includes a Shopify customer/dummy data generator for safely testing storefronts.
- **Sheets Tools**: Product-with-variations export, raffle/giveaway scripts, and an all-sheets-to-CSV exporter.
- **Zero Dependencies**: Runs entirely inside Google's Apps Script runtime — no server or hosting required.
